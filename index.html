Area petugas / admin

Versi awal yang aman: halaman ini tidak menyediakan tombol admin terbuka untuk mengubah stok atau menyetujui transaksi. Karena situs ini tanpa login, tombol admin yang bisa mengubah data akan dapat disalahgunakan siapa saja.

Untuk sementara, petugas mengelola data melalui Supabase Dashboard dengan akun petugas yang dijaga kerahasiaannya. Untuk admin langsung dari website, tambahkan login Supabase Auth dan kebijakan akses admin sebelum peluncuran.

Jangan pernah menaruh service_role key, password database, atau rahasia admin di file HTML/JavaScript publik.
